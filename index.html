02 — WEB APPLICATION

Budget Tracker

A simple way to plan a budget, record item costs, and see what's left. Your data stays in your browser between visits.

My contribution Built the interface, calculation logic, and browser storage.

  • HTML
  • CSS
  • JavaScript
  • Local storage
Live demo ↗Source code ↗ (opens in a new tab)
How it works +

The challenge

Keep a budget and individual purchases visible without requiring an account.

The solution

Set or top up a budget, add items with quantities and unit prices, then edit or remove them. Totals update immediately, with negative balances highlighted.

Implementation

Vanilla JavaScript manages calculations and local storage. Seven currency formats and a saved light or dark theme make the app more flexible. Currency selection changes formatting; it does not convert amounts.

Design takeaway

A useful interface needs clear feedback and predictable state. Browser storage keeps this app simple, while tying saved data to the current browser.
